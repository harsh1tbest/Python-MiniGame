# 🎮 Guess The Number Game

## 📌 About the Project
Guess The Number is a beginner-friendly Python game
where the computer generates a random number and
the player tries to guess it.

The game provides hints to help the player find
the correct number.

## 🛠️ Technologies Used
- Python
- Random Module

## ✨ Features
- Random number generation
- User input handling
- Hints for higher or lower guesses
- Interactive gameplay
